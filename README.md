# Progree IoT Internship Tasks

This repository contains IoT tasks completed during my remote Internet of Things internship at Progree. The tasks focus on embedded systems, sensor interfacing, firmware logic, cloud integration, MQTT communication and IoT automation.

## Tasks Included

### Task 2: Ambient Environment Node Simulation and Firmware Logic

Designed and simulated an ambient environment monitoring node using Arduino Uno and a DHT22 sensor. The system reads temperature and humidity values and displays clean telemetry on the Serial Monitor.

**Technologies used:** Arduino Uno, DHT22, Embedded C++, Wokwi, Serial Monitor

---

### Task 3: Real-Time Edge Data Pipeline Cloud Integration

Developed an edge-to-cloud IoT monitoring system using ESP32, DHT22 sensor and Adafruit IO. The ESP32 reads temperature and humidity values, connects to Wi-Fi and publishes the data to Adafruit IO feeds using MQTT.

**Technologies used:** ESP32, DHT22, Arduino IDE, MQTT, Adafruit IO, Wi-Fi, Embedded C++

---

### Task 4: Automated Threshold Smart Irrigation Gateway Infrastructure

Developed a smart irrigation gateway using ESP32, simulated soil moisture input, threshold-based control logic and Adafruit IO cloud monitoring. The system turns the pump indicator ON or OFF based on soil moisture thresholds, supports manual override and publishes irrigation telemetry to the cloud.

**Technologies used:** ESP32, Wokwi, potentiometer, LED, push button, MQTT, Adafruit IO, Embedded C++

## Key Features

- Sensor interfacing with Arduino and ESP32
- Embedded C++ firmware logic
- Real-time telemetry display using Serial Monitor
- Wi-Fi-based IoT communication
- MQTT publishing to Adafruit IO
- Cloud dashboard visualisation
- Threshold-based smart irrigation control
- Manual override logic
- Alert action configuration using Adafruit IO

## Main Project Highlight

The strongest task in this repository is Task 4, the Smart Irrigation Gateway. It demonstrates a complete IoT automation workflow, including sensing, decision-making, actuator control, cloud monitoring and alert logic.
